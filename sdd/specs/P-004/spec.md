# P-004 设置页聚合重构与展示优化（功能不变）

## 背景

- P-003 交付的设置页为线性 Setting 行排列（总开关/当前镜像/镜像池/添加表单/恢复初始），功能完整但信息密度与视觉分组不足
- 探索期（2026-09-07）经 demo 实证定案：原生 `SettingGroup` 聚合（since 1.11.0）+ 行尾箭头按钮展开交互，用户确认「完美符合预期」
- 缺陷随行修复：`addErrorEl` 声明后从未赋值，添加表单校验提示从不显示（P-003 AC3 实际只兑现禁用一半）
- 总约束：功能不变——引擎（`src/accelerator.ts`）零改动，全部交互语义保留
- 追加需求（用户定向，最后执行）：设置页全部可见文案英文化
- 开放问题决议（用户授权「全部做，先实现，根据效果调整」）：档二行级增量渲染纳入；desc 摘要沿用 `<REPO>` 口径；警示块落基础区；临时代码随实现收尾移除

## 用户故事

- 作为用户，我能在设置页看到分区聚合的卡片组（基础/镜像池/添加镜像），一眼定位
- 作为用户，我能通过行尾箭头按钮展开/收起镜像条目的映射详情，详情出现在该行正下方，箭头方向随状态翻转
- 作为用户，我能在条目名称前的状态点与 desc 中着色的测试结果（✓ 绿 / ✗ 红）一眼辨别镜像状态，无需独立当前镜像行
- 作为用户，填错添加表单时能看到具体错误提示（缺陷修复）
- 作为用户，未覆盖 GitHub 域时能在基础区看到醒目的警示块
- 作为用户，测试进行中或状态变化时界面平滑更新，无整表闪烁

## 范围内

- SettingGroup 四区聚合：基础（启用开关 + 未覆盖警示块）/ 镜像池（说明 + 条目列表）/ 添加镜像（SettingGroup 常驻）/ 恢复初始状态（独立区，置于设置页最后）；当前镜像不设独立行，由池条目状态点标识，Switch 按钮位于镜像池首行行尾
- 池条目：名称前状态点（当前使用=绿/普通=灰/已拉黑=红，等宽缩进）+ desc 测试结果（符号绑定颜色：✓ 恒绿 / ✗ 恒红，一映射一符号；其余文本默认色；整行对齐镜像名文本；去「镜像 N」序号）+ 行尾 `···` 按钮（原操作菜单：测试/上移/下移/删除）与 chevron 按钮（展开）；Switch 位于镜像池说明行（组首行）desc 右侧，不占条目行
- 详情展示：单行 `from → to`（渲染层去 `https://` 前缀与尾斜杠，不再拼接 `<REPO>` 占位；缩进对齐镜像名文本；存储值与引擎零变化）
- 池刷新：行引用跟踪 + 逐行 `settingEl.remove()`（替代 `empty()`）+ 行级增量更新（字段级 patch、DOM 顺序跟随池顺序、展开态保持）
- `addErrorEl` 缺陷修复：点击添加时集中校验（按钮随时可点、输入不触发校验，失败于提示行显示全部具体原因，合法时显示操作引导）
- 文案精简（heading/说明/desc 减半，保留关键语义）
- 设置页全部可见文案英文化（名称/描述/按钮/菜单/占位符/提示/空态/警示块）
- 临时示例块移除；manifest minAppVersion 定版 1.11.0
- styles.css 相应调整（状态点/测试结果着色/警示块/详情兄弟挂载适配，全用 Obsidian CSS 变量）

## 范围外

- 引擎行为任何变化（改写/游标/拉黑/冷却/测试逻辑）
- 映射编辑/保存（Modal 为未来提案载体）
- 声明式设置 API（`getSettingDefinitions`，未来提案）
- data.json 键名、代码注释、日志（英文化仅覆盖可见 UI 文本）
- 移动端、社区插件库发布

## 验收标准

AC1：设置页呈现聚合区（基础/镜像池/添加镜像），现有全部设置能力可用（功能不变）
AC2：池条目行尾箭头按钮点击 → 详情在该行正下方展开，图标 chevron-right → chevron-down；再点收起还原；多行可各自独立展开
AC3：详情单行展示映射（展示层去 `https://` 前缀、尾斜杠与 `<REPO>` 占位，如 `github.com → gh-proxy.com/https://github.com`；缩进对齐镜像名文本），存储值与引擎行为零变化（引擎单测 47 用例全过）
AC4：池条目名称前状态点分色（当前使用=绿/普通=灰/已拉黑=红，各行等宽缩进），desc 呈现测试结果且颜色绑定符号（✓ 恒绿 / ✗ 恒红，一映射一符号；其余文本默认色），与镜像名文本对齐，无「镜像 N」序号
AC5：添加表单按钮随时可点；点击时集中校验，失败于提示行显示全部具体原因（缺陷修复），全部通过即添加成功
AC6：添加镜像为独立 SettingGroup 常驻展示；「恢复初始状态」为独立区置于设置页最后
AC7：未覆盖 GitHub 已知域时警示块出现于基础区（含域名与经由镜像名），补全映射后消失
AC8：测试进行中或状态变化时池列表行级更新，无整表重建；展开态保持
AC9：无独立当前镜像行——当前镜像由池条目状态点（绿点）标识，Switch 按钮位于镜像池说明行（组首行）desc 右侧、不占条目行，「切换下一个」行为不变
AC10：设置页全部可见文案为英文，无中文残留
AC11：临时示例代码移除；manifest minAppVersion = 1.11.0；构建零错误 + lint 0 error 0 warning
AC12：引擎单测全过（55 用例 = P-003 基线 47 + 观测记账回归 8）——功能不变底线

## 边界与异常

- 空池：镜像池区显示空态提示（恢复初始状态仍可用）
- 1s 轮询仅更新组内行与表单提示，不重建组结构
- 行级增量渲染边界：增删镜像 → 增/删对应行；上移/下移 → DOM 行重排（详情随行携带）；状态变化 → 仅 patch desc
- 英文化不引入 i18n 框架（无多语言需求，直写英文）
