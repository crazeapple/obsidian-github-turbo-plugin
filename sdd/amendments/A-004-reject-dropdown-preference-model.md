# A-004 拒绝镜像下拉选择与直连兜底，采用「目录即偏好」（2026-09-03，关联 P-002）

状态：active

## 决策

设置页不提供镜像选择；内置目录有序（最优在前）即隐含偏好，插件全自动切换并只读显示当前 active 镜像；`mirrorBase` 存储键废弃，旧数据键忽略。

## 理由

「用户偏好」与「运行时现状」两概念纠缠于同一存储值，衍生 last-known-good 写回、显示漂移与迁移成本；目录顺序由维护者控制，天然编码偏好，模型更小且无需迁移。

## 否决备选

- 下拉选择 + 单值偏好——设置值要么脱离用户控制、要么切换状态不可见，两难
- 直连兜底（链尾直连哨兵）——静默降级掩盖故障，手动路径（关开关）已覆盖该场景

## 影响范围

P-002 设置页仅剩总开关与只读 active 显示；旧 `data.json` 的 `mirrorBase` 键被忽略；目录顺序成为唯一偏好载体，随插件版本发布更新。
