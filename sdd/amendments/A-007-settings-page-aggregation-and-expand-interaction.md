# A-007 设置页聚合选型与展开交互、映射展示形态（2026-09-07，关联 P-004）

状态：active

## 决策

设置页采用原生 `SettingGroup` 三区聚合；池条目展开交互 = 行尾 chevron 按钮（详情以兄弟节点插入行正下方）；映射详情展示 = 保留尾斜杠 + 尾部 `<REPO>` 占位（纯展示层拼接）。

## 理由

- demo 实证（2026-09-07，用户确认「完美符合预期」）：原生聚合卡片观感、主题适配零成本、`<details>` 无障碍免费；交互形态所见即所得
- `Setting.settingEl`/`nameEl` 公开，展开/挂载/行跟踪全部走公开 API；官方 `no-unsupported-api` 规则不可豁免，`SettingGroup`（since 1.11.0）硬性要求 minAppVersion ≥ 1.11.0——个人使用无旧版负担，接受
- 尾斜杠是存储真值与匹配边界（尾斜杠归一的承重结构），有损展示妨碍配置排查；`<REPO>` 占位补足「前缀规则、路径原样携带」语义，纯展示层拼接对存储/引擎/表单零影响

## 否决备选

- 自绘 section 卡片（路线 B）——minAppVersion 可不动，但需自维护 CSS 且复刻已验收的交互，无原生加成；若未来需要回退此路线，manifest 回退 1.2.3
- 名字点击展开（P-003 现行设计）——被行尾箭头按钮替代：可发现性更高、不占用名字点击语义（用户定向）
- hover Tooltip 展示映射——长 URL 不可读、不可复制、无触屏支持
- desc 常显全量映射——行高翻倍，池列表拉长
- 点击开 Modal 看详情——对高频轻需求偏重；Modal 留作未来映射编辑提案的载体

## 影响范围

`src/settings.ts`（聚合/交互/展示/英文化）、`src/styles.css`（徽标/胶囊/警示块/详情样式）、`manifest.json`（minAppVersion 1.11.0）；引擎 `src/accelerator.ts` 零改动。
